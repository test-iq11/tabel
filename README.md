# منظم الجدول المدرسي العراقي الذكي 🇮🇶📱

تطبيق أندرويد متكامل ومبني بلغة Flutter لدعم إدارة وجدولة الحصص المدرسية في المدارس العراقية دون الحاجة إلى اتصال بالإنترنت.

---

## 🌟 الوظائف والمميزات الأساسية

1. **إدارة المدرسة والعام الدراسي:**
   - دعم التوافق مع أنظمة المدارس العراقية (الابتدائية، المتوسطة، الإعدادية).
   - تخصيص أوقات الحصص والاستراحات وأيام الدوام الأسبوعي.

2. **الجدولة التلقائية الذكية (Auto-Scheduler):**
   - خوارزميات الذكاء البرمجي لتوزيع المواد والمعلمين دون تعارض.
   - كشف التعارضات المانعة والتحذيرات فورياً.

3. **محرر الجدول التفاعلي:**
   - تعديل الحصص يدوياً بسهولة وتبديلها.

4. **تقارير PDF احترافية وطباعة:**
   - دعم اللغة العربية واتجاه RTL.
   - طباعة وتصدير الجدول الشامل لكافة الشعب والصفوف بملف واحد.

5. **الأمان والعمل بدون إنترنت:**
   - بيانات المدرسة محفوظة تماماً في قاعدة بيانات SQLite محلية.

---

## 🚀 كيفية تشغيل المشروع محلياً

```bash
# 1. جلب الحزم المعتمدة
flutter pub get

# 2. تشغيل الفحص والتحليل
flutter analyze

# 3. تشغيل الاختبارات البرمجية
flutter test

# 4. بناء APK Release
flutter build apk --release
```

---

## 📦 GitHub Actions والـ CI/CD

المشروع يحتوي على سير عمل تلقائي يبدأ عند الدفع إلى المستودع (`.github/workflows/build-apk.yml`):
- يقوم بفحص الكود وتشغيل الاختبارات.
- يبني ملف `app-release.apk` تلقائياً ويرفعه كـ Artifact قابل للتنزيل من تبويب **Actions**.
