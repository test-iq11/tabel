# منظّم الجدول المدرسي العراقي الذكي

تطبيق Flutter لإدارة جداول المدارس العراقية محلياً على Android، بواجهة عربية RTL وقاعدة بيانات SQLite دون اشتراط اتصال بالإنترنت.

## ما الذي يتضمنه هذا الإصدار؟

- لوحة تحكم تُحسب إحصاءاتها من قاعدة البيانات.
- إدارة الصفوف والشعب والمواد والمعلمين وتأهيلات المعلمين.
- إعداد الحصص الأسبوعية المطلوبة لكل مادة ولكل شعبة.
- إدارة الأعوام الدراسية مع الاحتفاظ بالأعوام السابقة.
- إعداد أيام الدوام وأوقات الفترات وأنواعها (حصة، استراحة، نشاط، غير متاحة).
- محرر أسبوعي يدوي لجميع الشعب أو لشعبة محددة، مع إضافة/تعديل/حذف الحصص.
- كشف تعارض المعلم والشعبة والقاعة، والفترة غير المتاحة، ونقص/زيادة الحصص، والتأهيل غير الصحيح، والحصص دون معلم، وحد الحصص اليومية للمعلم.
- محرك جدولة آلية قائم على البحث مع ترتيب القيود الأكثر صعوبة أولاً وحد للبحث؛ يعرض النتيجة أولاً ولا يستبدل الجدول الحالي عند فشل التوزيع الكامل.
- إنشاء نسخة جديدة للنتيجة الآلية مع الاحتفاظ بالنسخة السابقة.
- تصدير الجدول الشامل إلى PDF وCSV، ومعاينة PDF.
- تصدير واستعادة نسخة JSON، مع التحقق من إصدار المخطط وحفظ نسخة طوارئ قبل الاستعادة.
- سجل تغييرات أساسي، وحالات مسودة/قيد التعديل/معتمد، ومقارنة مبسطة بين نسخ الجداول.
- اختبارات وحدات لمحرك كشف التعارضات والجدولة، وWorkflow لبناء APK.

## المتطلبات

- Flutter **3.47.7 stable** (Dart 3.13.5) أو إصدار مستقر أحدث متوافق.
- Java 17 لبناء Android.
- Android SDK مناسب لإصدار Flutter المستخدم.

## تشغيل المشروع

من مجلد المشروع:

```bash
flutter doctor
flutter pub get
flutter analyze
flutter test
flutter run
```

## بناء APK محلياً

```bash
flutter build apk --release
```

المسار المتوقع:

```text
build/app/outputs/flutter-apk/app-release.apk
```

يتضمن مجلد `android` ملفات Gradle وإعدادات التطبيق. ملف `android/gradlew` المرفق يحمّل توزيع Gradle الرسمي عند عدم وجوده في ذاكرة الجهاز، لذلك يحتاج أول بناء إلى اتصال بالإنترنت لتنزيل أدوات البناء والحزم. التطبيق نفسه لا يحتاج الإنترنت بعد تثبيت بنائه.

## بناء APK بواسطة GitHub Actions

1. أنشئ مستودعاً فارغاً في GitHub.
2. فك ملف ZIP ثم ارفع **محتويات** مجلد المشروع إلى المستودع (بحيث يكون `pubspec.yaml` في جذر المستودع).
3. ادفع الملفات إلى الفرع `main` أو `master`.
4. افتح تبويب **Actions** في GitHub واختر سير العمل **بناء تطبيق أندرويد**.
5. يمكن تشغيله يدوياً عبر **Run workflow**.
6. بعد نجاح المهمة افتح تشغيل الـ Workflow ثم قسم **Artifacts**، ونزّل `iraqi-school-timetable-release-apk`.
7. فك الملف المضغوط الناتج عن Artifact؛ سيحتوي `app-release.apk`.

يقوم الـ Workflow بتثبيت Flutter 3.47.7 وJava 17، ثم ينفذ `flutter pub get` و`flutter analyze` و`flutter test` وبناء APK، ويتحقق من وجود الملف قبل رفعه. لم تُنفذ هذه الأوامر فعلياً داخل بيئة إعداد الحزمة الحالية لعدم توفر Flutter SDK محلياً.

## الإعداد الأولي داخل التطبيق

1. افتح **إدارة البيانات** وأضف الشعب الفعلية لكل صف.
2. راجع المواد الافتراضية واحذف المواد غير المستخدمة أو أضف مواد المدرسة.
3. أضف المعلمين وحدد المواد المؤهلين لتدريسها، واضبط النصاب والحد اليومي.
4. افتح **الحصص المطلوبة** وسجّل عدد الحصص الأسبوعية لكل مادة ولكل شعبة.
5. من **المدرسة والأوقات** اضبط أيام الدوام والفترات حسب واقع المدرسة.
6. من **الجدول** أضف الحصص يدوياً أو جرّب الجدولة التلقائية. النتيجة الآلية لا تعتمد إلا بعد ظهور نجاح التوزيع الكامل وموافقتك.
7. من **فحص التعارضات** راجع الأخطاء والتحذيرات.
8. من **التقارير والنسخ الاحتياطي** صدّر PDF/CSV أو أنشئ نسخة احتياطية قبل التعديلات الكبيرة.

## قاعدة البيانات والنسخ الاحتياطية

تُخزن البيانات في SQLite في مساحة التطبيق الخاصة، وتشمل الأعوام والصفوف والشعب والمواد والمعلمين والتأهيلات وأوقات اليوم ومتطلبات الحصص ونسخ الجداول والحصص وسجل التغييرات. تصدير النسخة الاحتياطية يستخدم JSON يتضمن `schema_version` للتحقق من التوافق. الاستعادة تنفذ ضمن معاملة قاعدة بيانات واحدة؛ كما تُكتب نسخة طوارئ من البيانات الحالية في مجلد مستندات التطبيق قبل استبدالها.

## ملاحظة حول PDF العربي

يحاول مولّد PDF تحميل `assets/fonts/Arabic-Regular.ttf` إن أُضيف، وإلا يستخدم خط Noto Naskh Arabic أو Noto Sans Arabic من مسارات خطوط Android القياسية. بعض إصدارات Android أو الأجهزة المعدّلة قد لا تحتوي على أحد هذه الأسماء. عند ظهور رسالة تعذّر العثور على خط عربي، أضف خطاً عربياً مرخصاً للاستخدام باسم `assets/fonts/Arabic-Regular.ttf` ثم أعد البناء. لا يعتمد توليد التقرير على تنزيل خط من الإنترنت.

## حدود هذا الإصدار

هذا مشروع أولي وظيفي وليس شهادة باكتمال كل بند في المواصفات الطويلة. ما يزال يحتاج استكمال واختباراً على أجهزة Android فعلية لبعض الميزات المتقدمة مثل واجهة إدارة إتاحة كل معلم حسب كل فترة، إدارة القاعات من الواجهة، سياسة الفجوات بين حصص المعلمين، تفاصيل جميع تقارير النصاب والقيود المتتالية، واستعادة/مقارنة النسخ بواجهات أغنى. كذلك فإن توفر خط PDF العربي يعتمد على ما هو موجود على جهاز المستخدم أو إضافته إلى الأصول. لا يُعلن عن نجاح تحليل Flutter أو الاختبارات أو بناء APK إلا بعد تنفيذها فعلياً في بيئة Flutter.

## الهيكل العام

```text
lib/
  app/                 إعداد التطبيق والتنقل
  core/                الثيم والمساعدات العامة
  data/                قاعدة البيانات SQLite
  services/            الجدولة، كشف التعارضات، PDF، النسخ الاحتياطي
  features/
    dashboard/         لوحة التحكم
    data_management/   إدارة المدرسة والبيانات
    timetable/         محرر الجدول والجدولة التلقائية
    conflicts/         تقرير الفحص
    tools/             PDF وCSV والنسخ والاعتماد والأرشيف
test/                  اختبارات وحدات
.github/workflows/     بناء APK آلياً
android/               إعدادات بناء Android
```
