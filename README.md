# منظم الجدول المدرسي العراقي الذكي 🇮🇶📱

تطبيق أندرويد متكامل ومبني بلغة Flutter لدعم إدارة وجدولة الحصص المدرسية في المدارس العراقية دون الحاجة إلى اتصال بالإنترنت.

---

## 🌟 الوظائف والمميزات الأساسية
1. **إدارة المدرسة والعام الدراسي:** تخصيص أوقات الحصص والاستراحات وأيام الدوام.
2. **الجدولة التلقائية الذكية:** خوارزميات توزيع المواد والمعلمين ومنع التعارضات.
3. **محرر الجدول التفاعلي:** تعديل وتبديل الحصص بسهولة.
4. **تقارير PDF احترافية:** دعم RTL واللغة العربية وتصدير الجدول الشامل.
5. **SQLite المحلية:** عمل كامل بدون إنترنت.
